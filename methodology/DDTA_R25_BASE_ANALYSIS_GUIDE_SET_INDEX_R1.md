## Purpose

R42 consolidates the post-R37 Base Analysis guide work into two deliberately different views over the same BA contract. The two guides are companions, not competing authorities.

| Artifact | Intended use | Worked examples | Question-driven discrimination | Authority effect |
|---|---|---:|---:|---|
| `DDTA_BASE_ANALYSIS_CORE_GUIDE_R1_CANDIDATE_R1` | semantic/syntax reference base | no | no | none |
| `DDTA_BASE_ANALYSIS_COMPLETE_GUIDE_R1_CANDIDATE_R1` | end-to-end learning and operational selection guide | yes | yes, Q00-Q52 | none |

The current normative BA authority remains `DDTA_BASE_ANALYSIS_OPERATIONAL_GUIDE_R3.tex` together with the current BA0-BA5 artifacts. R42 does not promote, supersede, overwrite, or delete that authority.

## Core Guide contract

The Core Guide intentionally contains the BA semantic and syntactic contract without the pedagogical layers:

- BA authority and source-first discipline;
- BAReferent and BAProposition;
- detail criterion and stopping rule;
- current 14 top-level operator vocabulary;
- canonical signatures, roleKey semantics and cardinalities;
- condition language;
- selection working structure;
- pipeline/order pressure;
- R25 candidate constructs and rejected hypotheses;
- BA3, BA4, BA5, diagnostics and regression checks.

It intentionally excludes worked examples and the discrimination question pack. It is not a standalone promotion successor because that reduction is deliberate.

## Complete Guide contract

The Complete Guide preserves the Core Guide semantics and adds:

- source-grounded Facial Access examples;
- source-grounded DermaTriage examples;
- boundary and negative examples where a clean positive control is unavailable;
- Q00-Q52 question-driven discrimination;
- pairwise discriminators for ambiguous constructs;
- selection and pipeline decision questions;
- candidate/open stopping questions;
- semantic coupling matrix;
- quick question-to-construct matrix.

Intermediate construction checkpoints R39, R40 and R41 are not required as repository artifacts in this consolidated R42 set.

## Promotion gate

Neither guide becomes `CURRENT` merely by being present. Promotion still requires cumulative review against R3, preservation or explicit justification of every predecessor distinction, separation of evidence from authority, and explicit recorded promotion.
