\section{DDTA research work plan after documentation-layer
closure}\label{ddta-research-work-plan-after-documentation-layer-closure}

\textbf{WORK PLAN - REVISION 10}

\textbf{Status:} active BA2 execution plan after BA2-T2
operator/role/modifier vocabulary pressure testing.

\textbf{Supersedes:} Revision 9 only for forward execution state; R1-R9
remain historical research records.

\subsection{1. Fixed prior state}\label{fixed-prior-state}

\begin{itemize}
\tightlist
\item
  Chapters 2-4: CLOSED / FINAL for current thesis scope.
\item
  Documentation layer: CLOSED.
\item
  BA0-R systems-modeling prior-art research: CLOSED.
\item
  BA0 responsibility/non-goals: CLOSED.
\item
  BA1 minimal BAE identity ontology: CLOSED.
\item
  \texttt{BAReferent} and \texttt{BAProposition}: ACCEPTED first-class

\end{itemize}

\subsection{2. Closed BA1 identity
boundary}\label{closed-ba1-identity-boundary}

BA1 accepts exactly:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{BAReferent}
\NormalTok{BAProposition}
\end{Highlighting}
\end{Shaded}

BA2 must not introduce \texttt{Action}, \texttt{Relation},
\texttt{Participation}, \texttt{Role}, \texttt{Behavior},
\texttt{Information}, \texttt{Store}, \texttt{Contract},
\texttt{Boundary} or \texttt{State} as new first-class identity families
unless a concrete BA1 reopen criterion is met.

\subsection{3. BA2 objective}\label{ba2-objective}

BA2 defines the smallest stable methodology-neutral
proposition/relation/action semantics over the BA1 identities while
preserving:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{semantic identity family}
\NormalTok{    !=}
\NormalTok{semantic operator / participation role / modifier}
\NormalTok{    !=}
\NormalTok{lexical label / authoring synonym}
\end{Highlighting}
\end{Shaded}

Base Analysis must support mechanical selection and projection without
forcing consumers to reinterpret raw prose or import threat-method
categories.

\subsection{4. BA2-T1 - proposition structural lower
bound}\label{ba2-t1---proposition-structural-lower-bound}

\textbf{Status: COMPLETED / PROVISIONAL CANDIDATE.}

BA2-T1 rejects pure binary SPO as the universal proposition shape and
retains explicit n-ary role-bound participation with a stable semantic
operator and scoped modifier capability.

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{BAProposition}
\NormalTok{|{-} semanticOperator   1}

\NormalTok{|    \textasciigrave{}{-} term          1}
\NormalTok{\textasciigrave{}{-} scopedModifier     0..*}
\end{Highlighting}
\end{Shaded}

\subsubsection{Semantic boundaries
retained}\label{semantic-boundaries-retained}

BA2-T2 explicitly preserves:

\begin{Shaded}
\begin{Highlighting}[]
\NormalTok{correlation           != generic reference}
\NormalTok{service consumption   != ownership/management transfer}
\NormalTok{provider raw state    != governed project state}
\NormalTok{request acceptance    != physical handoff}
\NormalTok{realization           != generic local modifier when reusable}
\NormalTok{referent classification != participation role}
\end{Highlighting}
\end{Shaded}

\subsubsection{Modifier promotion rule}\label{modifier-promotion-rule}

A modifier remains embedded only when it is local to one
proposition/binding, has no new independent participant set, needs no
independent assertion provenance/review identity, and is not reused as
project meaning.

Otherwise model the meaning through explicit BAReferent/BAProposition
semantics rather than a modifier mini-language.

\subsection{6. BA2-T3 - cross-corpus regression and semantic-key/lexical
separation}\label{ba2-t3---cross-corpus-regression-and-semantic-keylexical-separation}

\textbf{NEXT / NOT EXECUTED BY THIS PLAN REVISION.}

BA2-T3 must replay the BA2-T2 candidate systematically against both
current corpora rather than inventing more vocabulary for reassurance.

It must test:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  whether every seed operator key is necessary or whether keys can merge
  without semantic loss;
\item
  whether any reviewed fact requires a missing method-neutral key or
  role distinction;
\item
  whether operator-scoped role contracts can assign compatible
  minimum/maximum cardinalities consistently;
\item
  whether the same semantic key remains stable across different source
  verbs and whether lexical synonyms can be separated cleanly from
  semantic identity;
\item
  whether explicit polarity avoids negative operator proliferation
  without weakening constraint semantics;
\item
  whether the modifier promotion rule keeps correlation, realization,
  responsibility and reusable constraints out of a generic modifier bag;
\item
  whether classification-as-proposition supplies the reusable
  semantic-kind distinctions needed by human/method consumers without
  reopening BA1;
\item
  whether the bounded STRIDE-oriented projection remains constructible
  without DFD/STRIDE leakage.
\end{enumerate}

\subsubsection{Exit condition}\label{exit-condition}

Produce a regression disposition for each candidate key/role/modifier
rule and identify the smallest unresolved set.

If the candidate survives but closure criteria still require a distinct
review, schedule that review. Do not close BA2 merely because the
current examples can be encoded, and do not invent additional microsteps
without a concrete unresolved falsification target.
