# Bibliography notes

The BibTeX file is a starter set, not the final bibliography.

Before thesis submission:

1. verify every record against the publisher, DOI registry, standard body, or official project;
2. replace access-year placeholders for evolving web guidance with the required citation style;
3. distinguish peer-reviewed versions from preprints;
4. record the exact version/date of standards and living guidance;
5. add page-specific notes only after reading the complete source;
6. never convert a synthesis inference into a source-derived claim.
