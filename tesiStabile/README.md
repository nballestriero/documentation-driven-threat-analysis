# tesiStabile

Repository delle specifiche definitive del metodo
Documentation-Driven Threat Analysis (DDTA).

## Ontologie

Le ontologie approvate sono organizzate in tre moduli:

- ontologies/core/DDTA_CORE.md
- ontologies/process/DDTA_PROCESS.md
- ontologies/security/DDTA_SECURITY.md

I documenti Markdown costituiscono le specifiche
di riferimento delle rispettive ontologie.

Ogni modulo potra contenere ulteriori artefatti,
inclusi i file Turtle.

Il repository raccoglie materiale approvato.
