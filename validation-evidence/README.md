# DDTA validation evidence

Status: ACTIVE EVIDENCE AREA

This directory stores evidence produced by validation, replication, review, or comparison activities around DDTA.

## Authority boundary

Material under `validation-evidence/` is **not** governed project documentation and is **not** normative DDTA methodology merely because it is versioned in this repository.

The authority flow remains:

```text
governed documentation
    -> Base Analysis
    -> deterministic/reproducible projections
    -> optional method-specific interpretation
```

Validation evidence may evaluate that flow, expose disagreement, record protocol deviations, or motivate later method review. It must not be projected back into project meaning as if it were governed source authority.

## Preservation rule

Original external reports are preserved immutably. Derived classifications, comparison matrices, and methodological conclusions must be stored separately and must identify their evidence basis.
