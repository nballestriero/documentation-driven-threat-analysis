## Authority boundary

Artifacts in this directory are review evidence and derived analysis.

They are NOT:

- governed DermaTriage project documentation;
- normative BA0–BA5 method definitions;
- automatic method changes.

The frozen BA contract remains the reference during individual reviews.

## Review rule

Each review starts from governed documentation and asks whether a general semantic distinction can be preserved using the current BA.

The order is:

```text
source text
    -> evidence-bearing wording
    -> governed semantic distinction
    -> current construct
    -> representation attempt
    -> preservation/generalization/minimality tests
    -> verdict
```

## Chat visibility

Material source evidence and the current construct must be shown in chat before the review verdict. Evidence-bearing wording must be highlighted so that the reason for the construct evidence is inspectable.
