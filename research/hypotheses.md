# Candidate hypotheses

All hypotheses are provisional until an evaluation protocol and metrics are approved.

- **H1 — Derivability:** documentation satisfying the DDTA input contract yields a
  Base Analysis model with measurable agreement against an expert reference model.
- **H2 — Traceability:** accepted threats and security requirements retain complete
  machine-checkable provenance to source documentation and analysis baseline.
- **H3 — Change awareness:** governed change-impact analysis identifies stale results
  with useful precision and recall.
- **H4 — Reproducibility:** independent analysts using the same baseline and method
  produce more consistent results with DDTA support than with an unstructured process.
- **H5 — Maintenance effort:** updating an existing analysis from documentation deltas
  requires less analyst effort than recreating the model manually.
- **H6 — Human oversight:** separating generated candidates from accepted findings
  reduces unsupported automated claims while retaining useful analyst assistance.
