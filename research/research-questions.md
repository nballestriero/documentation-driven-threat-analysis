# Research questions

## Primary research question

**RQ1.** To what extent can governed software documentation be transformed into a
security-analyzable canonical model that supports repeatable threat analysis?

## Secondary research questions

**RQ2.** Which documentation entities and trace links are necessary and sufficient
to derive the Base Analysis elements actor, component, asset, boundary, and data flow?

**RQ3.** How accurately and consistently can methodology-specific threat candidates
be generated from the derived model compared with expert-created threat models?

**RQ4.** Can baseline and traceability changes identify which analysis results have
become stale and require re-evaluation?

**RQ5.** Does governed expert review preserve provenance from documentation through
threat candidates to accepted security requirements and verification evidence?

**RQ6.** How does DDTA compare with manual threat modeling and threat-model-as-code in
coverage, effort, reproducibility, maintainability, and explainability?
