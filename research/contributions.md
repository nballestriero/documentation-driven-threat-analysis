# Candidate research contributions

1. A formal definition of Documentation-Driven Threat Analysis and its boundaries.
2. A methodology-neutral Base Analysis metamodel derived from governed documentation.
3. A provenance model linking documentation, analysis candidates, expert decisions,
   security requirements, implementation, and verification evidence.
4. A baseline and change-impact mechanism for continuous threat-analysis maintenance.
5. A human-in-the-loop lifecycle separating proposed, reviewed, accepted, rejected,
   superseded, and stale analysis records.
6. ThreatForge as a reference implementation and experimental instrument.
7. An empirical evaluation corpus and reproducible study protocol.

These are candidate contributions; novelty must be established source by source.
