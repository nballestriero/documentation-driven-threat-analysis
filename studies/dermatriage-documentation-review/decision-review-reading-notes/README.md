# DermaTriage Decision Review Reading Notes

This directory preserves intermediate research/validation artifacts produced while reviewing the first Decision family under `MR-01` during the R25 DermaTriage holdout.

These files are **not** the governed DermaTriage documentation baseline and are **not** Base Analysis artifacts. They preserve the evolution of the methodology-validation discussion between the immutable guided-review checkpoint `r1/` and the future cumulative `r2/` milestone.

## Notes

- `note-01/` — first explicit Decision review record for `DEC-01`, including gate questions, evidence, answers, dispositions, STOP and provisional methodology evaluation.
- `note-02/` — revised reading note preserving the same governed meaning for `DEC-01` while distinguishing **Research / Validation mode** from **Operational / Assisted authoring mode** and refining the interpretation of procedural verbosity.

Both notes are intentionally preserved rather than overwritten so the evolution of the methodology assessment remains inspectable.
