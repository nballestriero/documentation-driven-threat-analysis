## Revision rule

Guided-review revisions are preserved as immutable research checkpoints rather than overwritten:

`r1 -> r2 -> r3 -> ...`

A new revision is created at a meaningful semantic milestone, not for every editorial change. Each successor records what remained stable, what changed, which gate caused the change, and why.

The guided-review record is research evidence. It is distinct from the clean DermaTriage DDTA project documentation candidate that will be assembled from accepted elements and may become a documentation baseline only after the documentation gate passes.
