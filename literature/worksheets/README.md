# DDTA worksheets

The PDF files in this directory are generated research aids and may be printed.
The reusable research record is the matching Markdown note and YAML excerpt ledger:

```text
worksheets/<SOURCE-ID>_scheda_compilata.pdf
notes/<SOURCE-ID>.md
excerpts/<SOURCE-ID>.excerpts.yml
```

The blank worksheet is `DDTA_modello_scheda_lettura_v2.pdf`.

Do not treat a worksheet as a source. Every statement used in the thesis must resolve
to a registered source and an exact location. Temporal validity is mandatory.
