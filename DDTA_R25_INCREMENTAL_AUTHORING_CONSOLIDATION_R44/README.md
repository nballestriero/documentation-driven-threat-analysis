# DDTA R25 Incremental Authoring Consolidation R44

This drop-in consolidates the current incremental documentation-authoring work without promoting it to current methodology authority.

It contains:

- the rebuilt Documentation Authoring Guide snapshot (`R7_REBUILD_R1`);
- the current DermaTriage parallel case study snapshot;
- a reusable per-page LaTeX payload MD5 updater at `tools/update_page_md5.py`;
- consolidation metadata and continuation instructions.

The package is designed to be extracted at the repository root.
