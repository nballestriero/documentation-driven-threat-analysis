# Historical and reference materials (read-only)

`dermatriage/DDTA_DERMATRIAGE_GOVERNED_DOCUMENTATION_R1.pdf` is a reference snapshot used to reconstruct the new DermaTriage documentation. It is not a runtime dependency of the renderer and does not become a source of authority *inside* newly authored MR/DEC/FR documents.

Legacy DDTA projects, guides, BA-to-Mermaid experiments and original DermaTriage cases are intentionally **left where they already exist** in `TESI`. No legacy paths are deleted or overwritten.

Future migration should explicitly map legacy artifacts to their new equivalent, review their status and only then archive/retire old duplicates.
