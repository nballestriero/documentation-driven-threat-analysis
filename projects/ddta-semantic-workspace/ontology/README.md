# Ontology sources

`core.ttl` is the currently supplied baseline. Keep it generic: system, function, process, information, contract, artifact, store, environment, boundary and transfer abstractions.

Future ontology modules (`ai.ttl`, `security.ttl` and any integration/bridge) will be added only when their meanings are discussed and approved. The future guides are deferred until the ontology settles.

**Identity note:** ontology IRI: `https://w3id.org/ddta/core`; term namespace: `https://w3id.org/ddta/core#`. This migration changes the actual RDF IRIs, not only the display prefix. See [IRI_POLICY.md](IRI_POLICY.md).
