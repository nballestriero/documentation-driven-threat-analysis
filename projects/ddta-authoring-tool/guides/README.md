# DDTA Authoring Tool — Guides

- [`ba/`](ba/README.md): canonical Base Analysis guidance, common proposition contract, and operator guides.
- [`mermaid/`](mermaid/README.md): independent BA-to-Mermaid projection guidance.

Operator definitions and cardinalities are read from their Markdown guide contracts; the executable set is controlled by each guide's `reviewStatus`. Document-format validation and BA structure validation are distinct from evidence-based semantic review.
