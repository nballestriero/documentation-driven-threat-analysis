# FR-MR01-02-02 — Creazione del template documentale governato

**Parent Decision:** `DEC-MR01-02`\
**Lifecycle:** `candidate`\
**Authority:** `EXPERIMENTAL_NON_CANONICAL`\

## Functional obligation

Fornire una nuova struttura Markdown appropriata al tipo DDTA selezionato.

## Normative clauses

- **NC-1:** Quando l’autore richiede un nuovo documento di un tipo supportato, la funzione di creazione MUST produrre la struttura dei campi previsti dallo schema governato selezionato.
- **NC-2:** Il template MUST distinguere campi richiesti e facoltativi secondo il contratto dello schema e MUST NOT riempire con affermazioni di progetto non fornite dall’autore i campi che richiedono significato governato.

## Riferimenti SPO e BA

**Da derivare in una successiva passata BA.** Non creare referent o proposition dalla sola ipotesi di modulo Python.

## Esempio di assessment (supporto di review, non normativa)

Creare template MR, Decision, FR e specializzazioni; confrontarne i campi con gli schemi versionati.
