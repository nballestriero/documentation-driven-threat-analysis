# FR-MR01-02-02 — Creazione del template documentale governato

**Parent Decision:** `DEC-MR01-02`\
**Lifecycle:** `candidate`\
**Authority:** `EXPERIMENTAL_NON_CANONICAL`\

## Functional obligation

Predisporre una struttura Markdown conforme al tipo di sorgente DDTA selezionato, includendo template per documenti e Base Analysis senza generare manualmente la proiezione Mermaid.

## Normative clauses

- **NC-1:** Quando l'autore richiede una nuova sorgente di un tipo supportato (documento DDTA o BA), la funzione di creazione MUST produrre la struttura dei campi previsti dallo schema governato selezionato.
- **NC-2:** Il template MUST distinguere campi richiesti e facoltativi secondo il contratto dello schema e MUST NOT riempire con affermazioni di progetto non fornite dall'autore i campi che richiedono significato governato.
- **NC-3:** Quando viene richiesto un template BA associato a un documento DDTA identificato, la funzione MUST predisporre il collegamento dichiarativo a tale documento senza inventare BAReferent o BAProposition. La correttezza del riferimento sarà verificata tramite i servizi di `MR-03`.

## Riferimenti SPO e BA

**Da derivare in una successiva passata BA, in file Markdown separato collegato a questo FR.** La presente sezione è una nota di review, non una BA canonica.

## Esempio di assessment (supporto di review, non normativa)

Creare template MR, Decision, FR e specializzazioni, poi un template BA associato a un FR esistente. Verificare campi e collegamento dichiarato rispetto agli schemi. La creazione di un template non deve generare un diagramma Mermaid: la proiezione dipende dalla BA e da `MR-04`.
