# FR-MR01-01-02 — Selezione dello scope documentale

## Functional obligation

Selezionare i documenti da elaborare a partire da un file oppure da uno scope di cartella esplicito.

## Normative clauses

- **NC-1:** Quando l’utente seleziona un file DDTA, la funzione di selezione MUST includere tale documento nello scope richiesto.
- **NC-2:** Quando l’utente seleziona una cartella, la funzione di selezione MUST determinare l’insieme dei documenti da includere secondo una convenzione documentata e applicata in modo riproducibile.
- **NC-3:** Quando una selezione non può essere risolta, la funzione MUST restituire una condizione di errore identificabile senza presentare uno scope incompleto come completo.

## Riferimenti SPO e BA

**Da derivare in una successiva passata BA.** Non creare referent o proposition dalla sola ipotesi di modulo Python.

## Esempio di assessment (supporto di review, non normativa)

Confrontare due selezioni ripetute sul medesimo workspace; verificare file inesistente e directory con file non DDTA.
