# FR-MR01-02-01 — Identificazione dichiarativa del tipo e dell’identità documentale

**Parent Decision:** `DEC-MR01-02`\
**Lifecycle:** `candidate`\
**Authority:** `EXPERIMENTAL_NON_CANONICAL`\

## Functional obligation

Riconoscere tipo e identità di un documento a partire dalla dichiarazione contenuta nel sorgente.

## Normative clauses

- **NC-1:** Quando una snapshot DDTA viene interpretata, la funzione di identificazione MUST ricavare il tipo documentale e l’identificatore dai campi dichiarati nel contenuto secondo lo schema applicabile.
- **NC-2:** La funzione MUST NOT assumere il tipo o l’identificatore come validi soltanto in base al nome del file.
- **NC-3:** Quando la dichiarazione di tipo o identità è assente o non interpretabile, la funzione MUST produrre un risultato di interpretazione non riuscita utilizzabile dal servizio di diagnostica.
