# TS-FR-MR02-03-01 — Verifica della coerenza del catalogo degli operatori BA

## Purpose

Verificare l'invariante di corrispondenza completa fra le guide valide contenute nella cartella degli operatori e gli operatori riconosciuti dal motore. Non si richiede un insieme prefissato di nomi ne si verifica l'assenza di architetture storiche.
