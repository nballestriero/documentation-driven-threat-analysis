# TS-FR-MR03-06-02 — Verifica dei riferimenti reciproci per i casi di test

## Purpose

Verificare la corrispondenza fra l'identita del caso nel documento, il binding al metodo Python e la dichiarazione inversa del metodo. Il controllo valuta la struttura dei riferimenti, non la correttezza semantica del test.

## Test cases

```yaml test-cases
cases:
  - id: TC-FR-MR03-06-02-01
    covers: [NC-1, NC-2, NC-3, NC-4]
    rationale: Una specifica e il relativo metodo devono riferirsi univocamente allo stesso caso sotto un FR esistente.
    preconditions: Scope di prova con FR, TestSpecification e metodo Python dichiarati.
    action: Verificare la corrispondenza reciproca; poi alterare il riferimento nella docstring della funzione di test e rieseguire.
    expectedResult: Il riferimento reciproco coerente viene riconosciuto, mentre quello discordante genera una diagnostica senza PASS.
    testBindings:
      - prototype/generic-v01/tests/test_test_trace.py::TestTraceabilityTest.test_bidirectional_links
```
